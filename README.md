**Location-or-Term Unified Search for Brain Functions** - A web application for logical brain function search.

LoTUS-BF is a web application that fuses the user interface of NeurosynthSearch with the backend functionality of LoTUS-BF, providing a three-column layout for searching and analyzing neuroscience literature.

## Quick Start

1.  **Setup Environment:**
    *   Install Node.js LTS: `nvm install --lts`
    *   Clean old packages: `rm -rf node_modules package-lock.json`
2.  **Install Dependencies:**
    ```bash
    npm install
    ```
3.  **Run Development Server:**
    ```bash
    npm run dev
    ```
4.  **Open in Browser:**
    Navigate to `http://localhost:5173`

### Available Scripts

*   `npm run dev`: Starts the development server.
*   `npm run build`: Builds the project for production.
*   `npm run lint`: Lints the code using ESLint.
*   `npm run preview`: Previews the production build.
*   `npm run deploy`: Deploys the `dist` directory to GitHub Pages.

## Key Features

*   **Three-Column Layout:** Trend analysis | Paper list | 3D brain image viewer.
*   **Powerful Search:** NeurosynthSearch style + LoTUS-BF logical operators.
*   **Real-time Analysis:** Year trend chart + journal ranking + direct links to PubMed.
*   **Modern Design:** Coral Red + Tiffany Blue color scheme.

## API

The application uses the LoTUS-BF backend API. The available endpoints are:

*   `/terms`: Get a list of all terms.
*   `/terms/<term>`: Get details for a specific term.
*   `/query/<query_string>/studies`: Get a list of studies for a given query.
*   `/query/<query_string>/locations`: Get a list of activation coordinates for a given query.
*   `/query/<query_string>/nii`: Get a NIfTI 3D image for a given query.

**Location-or-Term Unified Search for Brain Functions** - 邏輯性大腦功能搜尋融合網頁應用

## 📋 快速開始

```bash
# 安裝 Node.js LTS
nvm install --lts

# 清理舊套件
rm -rf node_modules package-lock.json

# 安裝依賴
npm install

# 本地開發（http://localhost:5173）
npm run dev

# 構建發佈版本
npm run build

# 預覽構建結果
npm run preview
```

## 🎨 應用特色

- **三欄佈局**：趨勢分析 | 論文列表 | 3D 腦影像查看器
- **強大搜尋**：NeurosynthSearch 風格 + LoTUS-BF 邏輯運算符
- **實時分析**：年份趨勢圖 + 期刊排名 + PubMed 直連
- **現代設計**：Coral Red + Tiffany Blue 配色系統

## 📦 核心依賴

- React 19 - UI 框架
- Recharts 2 - 交互式圖表
- @niivue/niivue - 3D NIfTI 醫學影像查看器
- Axios - HTTP 客戶端
- Vite 7 - 現代構建工具
